# 🧩 Human Picture Verification Game

A small, GitHub Pages-ready **picture-selection human verification game**.

The player is asked to select every picture matching the target category. The challenge is generated from the image pool and checked locally in the browser.

## 🚀 Demo

After enabling GitHub Pages for this repository, open the Pages URL:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## 📁 Files

- `index.html` — the complete verification game
- `assets/` — original game images
- `README.md` — this documentation

## 🎮 How it works

1. A target such as **ocean** is displayed.
2. A 3×3 grid of pictures appears.
3. Click every picture matching the target.
4. Press **Verify I'm Human**.
5. The game reports whether the selection is correct.
6. A new challenge can be generated with **New Challenge**.

## 🌐 GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose your main branch and `/ (root)`.
6. Save.
7. Open the GitHub Pages URL shown by GitHub.

## ⚠️ Important

This is a **fun front-end game**, not a real security CAPTCHA. Because all verification logic runs in the browser, someone who controls the page can inspect or modify it.

For real authentication or anti-bot protection, use a server-side verification service.
